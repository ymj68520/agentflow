## Complete source census and exclusions

Frozen model@6 has208 Raw-input reachable nominal types and232 types in the
union of supported Raw witness/C output closures. The source-derived census
has317 inline value-constructor sites, including147 G1 input container sites.
The enlarged denominator includes output payloads and inline primitive/unit
constructors; it does not recast G1's147 as runtime coverage. Named references
terminate local syntax traversal; alias bodies delegate to the actual declaring
type. Every site is backed by an exact parent descriptor and closed selector
path. New site value types get opaque, table-allocated names, not runtime names,
shape hashes or field-concatenated temporary TypeIds. Old97 imports retain owners.

Graph/Scope/Fact/report metadata is not thereby eligible as an input value node.
The source census is not a list of synthetic roots. Other producers/profiles
remain unimplemented. All affected Source/Target/Origin/Basis/Witness/Evidence
references receive an explicit domain audit even when they are plain output
records rather than W value nodes.

## Necessary rank-free entry and explicit current consumer delta

RawParsedInput already contains Node<DocumentOccurrenceBinding> fields. It is
not a legal *unbound* prerequisite for building that same graph. The registered
source contract therefore consumes complete Compiler, expanded SourcePackage
metadata, complete OwnerAnchor and actual entry ordinal, true internal paths,
physical source association, the actual Raw candidate and full actual Context.
Its descriptor closure must contain **no dag_ref**. Existing expanded document
companions are source inputs only, not substitutes for complete Node carriers.
Future native association receipts must be genuine and lifetime-bound; caller
claims/native_associated enum values never create such a receipt.

The successor ScopeSubject.raw_contract_validation must explicitly carry
`{subject:Node<RawValidationSubject>}` and declare that one G root. The frozen
model@6 raw branch is an inline RawValidationSubject; it is retained unchanged
there, not silently reinterpreted. New Source/Target/Basis/Witness references
resolve that exact current G Subject. Candidate data may exist before C only in
the successor; complete Fact use additionally requires genuine source admission
and all actual Some C Valid results. The admission result is outside G.

## G/W grammar and DAG rules

G appends map to NodeBody after all seven existing cases. Map entries are metadata
`{key:DagRank,value:DagRank}`, not extra value nodes. Local children flatten key
then value in complete typed-key order; reject duplicate canonical keys before
interning. Native SpecificationId parsing is canonical/injective on valid ASCII
identifiers; a valid native key must equal its full CompiledSchema specification.
All complete canonical type definitions are preserved, not just schema digests.

W has a separately registered body grammar: record/variant/list/set/option/map
edges are explicitly `local:DagRank` or `input:DagRank`. Input edges resolve in G
only at registered dag_ref sites; ordinary U64 data is never a reference. W has
local heights (zero with no local child), typed external-target payload keys and
ordered local-child ranks. Complete envelope equality includes full G, tuple,
profile and root environment. No bare-number arena fallback or graph-hash identity.
G's0217 height, reachability, minimality, full equality and deterministic rank law
are unchanged. New type ordering preserves the774-entry prefix; numbers denote
type registration ranks, never produced value DagRanks.
Reference-policy keys also bind carrier use (G value, W value, plain output),
because an input type reused in W/output still has external input references.
The explicit StructuralReferenceUse declaration closes this use-site distinction;
no caller chooses an arena from a bare integer or declaring type alone.

ACE1 v1 already represents this using explicit record/variant/list and numeric
primitive shapes. No new ACE1 grammar, AFIDL primitive, HashV1 domain or native
layout reflection is required. Independent typed encoding fixtures must prove
the new map/W-edge representation under the unchanged grammar.

## Implementation acceptance boundary

Only catalogue/shape/site/admission metadata and explicitly bounded, manually
provided registration subgraphs are checked. No entry constructs a production
graph or assigns ranks to actual complete Raw inputs. Production profile entry
returns NotImplemented regardless of metadata success. Source/alias/field/variant
rosters must be independently derived, not learned from Rust Actual or emitted
table counts. Unknown full-field Nested/Relation denominators remain unknown.
