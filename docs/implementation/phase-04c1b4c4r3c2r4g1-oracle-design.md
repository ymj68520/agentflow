# Independent future Oracle algorithm / 48 Not Executed design vectors

**Algorithm design only.** No value DAG, formal DagRank, Map encoder, complete
Raw Oracle or normalizer is implemented by G1's evidence-inventory script.
The script only reads all prior evidence/registered descriptors, records closed
sites/actual source provenance, validates design metadata and writes design lists.

Future Oracle inputs must be actual complete source package/owner/slot/physical
or native declaration, actual compiled definitions and all nine universes/A
snapshots, implementation-owned full compiler/support content, actual stage and
association evidence, and the separately registered successor site/root/reference
environment tables. It must derive its own event/premise applicability from
declarations and frozen algorithms. Rust Actual is never an Expected constructor.

Independent design steps, with no execution claimed:

1. Pin/check exact source/Registry/model content and closed descriptor/alias/site
   tables. Reject old/mixed/unknown content under PP identity taxonomy. Keep a
   source-derived required profile/root roster independent of both data views.
2. Recursively enumerate required logical values/fields and actual selected
   variant/option/sequence/map/set sites from complete declarations. Reject
   missing data; retain actual native empty universes and Raw byte strings.
   Distinguish observed source values from structurally possible inactive cases.
3. Resolve every expected node type/nominal site and per-field reference domain.
   Derive child-target types, complete values and input/payload graph membership.
   No invented type names, map-as-string substitutes or U64-as-node coercions.
4. Independently validate source/occurrence/native Context association, set/map
   constraints and C slot applicability; derive actual native-schema revalidation
   results from full native catalogs/current modules, not error strings or Rust
   Actual. A Some C Missing execution requires failure evidence, not a full Fact.
5. Derive complete typed equality classes with full equality (a hash is only an
   accelerator), semantic key/member order and all required parent edges. Keep
   occurrence and observation identity separately; content sharing does not
   collapse distinct legal O values or changed current Context observations.
6. Prove input/output acyclicity, complete closure and authorized root reachability.
   Independently compute local heights and the registered canonical type/body/
   child order; derive expected contiguous U64 ranks within each graph, only in
   a future authorized implementation. G1 vectors name symbolic dependencies and
   leave assigned_ranks null. Cross-arena inputs resolve only in exact G.
7. Compare Expected/Actual node rosters, full types, values, root order, equality
   classes, all local/external refs and canonical ranks/bytes. A second source-
   and-descriptor-derived required roster rejects simultaneous deletion from
   Expected and Actual, including an entire node or its reference/type/root.
   Do not learn the denominator from either projected view or Rust's emitted list.
8. Only later authorized Raw conformance compares all14 roots, nested descriptor
   instances, Basis/Witness, Source/Origin, EvidenceRef/primary, Consumer and
   Observation links. Report required/compared/missing/partial/uncompared and
   unexpected mismatches explicitly; UNKNOWN denominators remain null, not zero.
   Binder success does not imply full Raw success, a completed G01 Fact or T4 entry.

Comparator attacks must include single- and both-sided node/type/value/child/
reference/root omissions, wrong nominal owner, equal-shape casts, wrong arena,
rank permutation, redundant sharing, source occurrence collapse, false C Valid,
T4 bootstrap/output backedges and injected RootExport capability. Nothing in this
plan generates a current valid proof object. Registered-model bounds and D0–D10
limits intersect throughout; resource exhaustion returns no successful prefix.
