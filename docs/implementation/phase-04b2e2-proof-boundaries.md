# Phase 4B.2E.2 — Static Proof Boundaries

## Established

For exact checked IR/export inputs, pointer-identical proof context, complete
typed context content, canonical typed maps, a valid compiler semantics
identity and complete source closure, the checker can report I/O, Phi,
epsilon/K, R, F, U, K and per-child X feasibility/security independently.
Only nine Proven dimension results permit
`Static Root/Export Contract Compatibility: Proven`.

## Deliberate non-claims

- `body_conformance` and `implementation_conformance`: RequiresEvidence;
- publisher authentication: NotEstablished;
- runtime authority: NotEstablished;
- Scope authority and budget attenuation: Unproven because frozen ScopeBody
  has neither ceiling;
- Worker placement/admission, grants, handles, reservations, receipts,
  settlement and recovery dispatch: not created or inferred.

Unknown catalogs, open rows, absent resource/Flow/X coordinates, incomplete
subflow closure, transformed input identity and unsupported Recovery
monotonicity remain Unproven. An exact typed contradiction may be Violation;
failure of a containment routine alone is not automatically a counterexample.

## Freeze boundary

No Semantic IR, ComponentContract, Effect, Recovery, Usage AFIDL, ACE1,
HashV1, existing digest, ABI assignment, WorkflowVersion, ExecutablePlan,
Journal, Reducer, Runtime, Scheduler or Worker surface is changed or added.
