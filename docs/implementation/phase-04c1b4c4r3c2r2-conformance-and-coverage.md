comparisons. It changes all four owner keys, document Slot, internal declaration

and unchanged fields for every compared local source/event value. These are not
full formal Fact sensitivity proofs. Compiled-constraint sensitivity and complete

R2-H acceptance. Output mutations are not relabelled as real input changes.
