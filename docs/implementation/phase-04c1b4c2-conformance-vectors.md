## Complete expected-value contract shared by each row

Original IDs D01–D48 refer exactly to [accepted48 design vectors](phase-04c1b4c1-decision-vectors.md). Preserve that document. Proposed execution edition **E2** means owner@2 +OS/RM/PP2 exact future tuple,report-shape1,obligation1, as [defined](phase-04c1b4c2-compiler-edition.md), not an unresolved old current-profile alias. Every row's required edition is E2; M01/M10 explicitly submit old content **to** E2.

Instantiate a complete coherent S_v from independently authored new-edition inputs: every compiler/source/registry byte,all context members/relations/resolver associations/root provenance/raw assertion graph,role partition and all real declarations supplied. No partial symbolic Scope may enter actual conformance. For design comparison, `I_v` is the **full** identity set specialized by the original row's complete Id constructor and the row premises below, lifted to the approved E2 tokens and all required typed fields; `O_v` contains all statuses,dispositions,prerequisite links,refs,primary,counterexamples,companion evidence and observation sets. B,b1–b6,F0,I2/I10,A0/A1,K0/Ka/Kb,X0/Xf/Xs retain their exact accepted complete definitions, not bare English names. Scope changes coherently whenever an identity-bearing declaration changes. Claims of old identity stay claims, not the analysis owner.

Every row's expected canonical string is **C_v(i)=UTF8(ACE1_RM(complete i))** for each i in typed order, including the entire S_v and minimal DAG; full expected view is `V_v=sorted O_v + [C_v(i)] + exact fact/prerequisite/blocker/contradiction indices`. A failure row has **no string/view**, not an empty-string/empty-set replacement. "Unequal" requires comparing all complete identity components and exact bytes; order is the row order or the registered typed order, never string sort. FullRoot eligibility additionally requires successful bounded normalization before capability creation. Fragment eligibility is NotApplicable and constructs no RootExport capability.

These are complete symbolic Expected *relations*, not materialized future golden bytes: future source content has not been registered. The implementation must generate every concrete byte independently at T6 before execution and freeze them in a new namespace. This plan does not claim that C_v is an already available encoder.

Comparator contract ALL: every scope/identity field,ModelType/nominal width/option/variant/set/sequence,Fact status/evaluation/role/cause keys,prerequisite status/support/consumers,reference set/primary,disposition,contradiction,observations,runtime companion,blockers,canonical identity string bytes/order,typed error stage/category and capability boundary. Diagnostic reasons are presence/type-checked only after no essential content is lost. For identity-only rows compare full identity+bytes; for ref rows full scoped refs; for errors compare exact stage/category/no successful view/no capability. Never compare only identity_strings.
