# Registered values, canonical carrier and reference use

Normative sources: structural-binding@1 rules0302–0309, OS@7 rules0310/0311,
model@7 rule0312; underlying0214/0215/0217/0218/0219/0256 remain in force.

## 317 actual source sites, not a runtime denominator

The census follows frozen model@6 Raw input and supported Raw witness/C closure.
Named references stop local selector expansion; declarations are reviewed once.
317 inline constructor sites include G1's147 input containers, output payloads,
inline unit/scalar constructors and positional tuple records. Each registered row
has true owner/parent, exact selector path, complete alias definition, child types,
source model/stage, nominal identity, eligibility and reference/rank policy.

StructuralValue names are opaque, explicitly allocated registration table entries.
They are not source ordinals, runtime counters, shape hashes or concatenated field
paths. Body aliases delegate to their actual declaring type/path. Same shape under
different owner/site is not a cast. The old97 selected imports keep exact owners,
names/full descriptors; the old774 rank prefix is preserved. New type registration
ranks are never DagRanks. Graph/Fact/Scope/report metadata does not become a G value
node merely by having a registered shape. No extra source-less sites are accepted.

## Map versus Set

NodeBody appends map after its seven old cases. StructuralMapEntry is wire/body
metadata with key/value child ranks, not an extra value node. Full typed keys
order entries; duplicate canonical keys reject before interning. Key then value
form the ordered child list; count is nonrecursive metadata. Empty map height0,
otherwise1+maximum local child height. No Debug/hash iteration/rank-spelling sort.
String-map NFC rules apply only in their domain; Raw bytes are not normalized.

Set's old body is unchanged. Each actual Set has its exact member source/type and
original semantic-key/full-payload/minimum constraints. Repeated equal supplied
membership rejects, sequence repetition remains. No global Map-key overwrite rule
is imposed on record-valued Sets; native storage does not reveal insertion history.

The normal0217 algorithm still validates types/widths/sets/cycles/closure, interns
full equal typed values bottom-up, orders by height/type/nonrecursive payload/
ordered local child ranks and requires contiguous U64 numbering, earlier children,
exact roots/reachability and no redundant equal nodes. Numeric comparison is
mathematical, decimals exact, finite floats follow frozen zero handling; rank
numbers are representation, not numeric semantics. Complete typed comparison is
not host object equality or hash-only matching.

## G / W / plain outputs

66 exact policy rows distinguish carrier use as well as declaring field:
g_value, w_value, output_record. A reused RawInputOrigin field is G-local in G
but points externally into G from W/plain outputs. Parent-type membership alone
cannot choose its arena. Ordinary U64 fields remain scalar data.

G contains immutable inputs only. W has its own body grammar with local/input
edge tags. External edges are direct exact typed G references, not scalar-U64
wrappers. They add no W-local height; no local children means height0. Their
nonrecursive payload key compares complete typed G targets. W-local ordering,
minimality, roots and reachability remain required. Complete envelope equality
also includes full G, exact tuple/profile/root environment. Equal bare W numbers
or a graph checksum under another carrier do not establish equal evidence.

Manual fixtures validate supplied graphs/ranks against independently declared
expanded typed source values. They never construct a production graph or assign
actual Raw ranks. Registration input/output graphs are bounded by64 nodes,
depth32 and16,384 work/value units, intersecting the unchanged full model limits.
Resource failure returns no graph. Unsupported source profiles do not gain fake
types/sites simply to exercise a test (e.g. plain float is not a Raw guard input).

ACE1 remains v1: explicit variant/list/record/U64 shapes encode map bodies and
W input/local edges. Rust typed encoding is compared to independent exact bytes.
No new AFIDL primitive, HashV1 domain or native layout reflection is introduced.

## Complete source composition under the existing size bound

A fully duplicated nested model source made Compiler identity38,836,805 bytes,
above the frozen33,554,432-byte native bound. No limit was widened and no source
was dropped. Model@7 instead has a closed delta over complete exact model@6 bytes.
Full base contents remain in the compiler/Portable source inventory and compiled
implementation-owned data. Expansion is lossless and compared to the complete
effective catalogue; checksums check available bytes, never replace them.

The only old-name successor replacements are NodeBody and ScopeSubject. Names,
ranks, fields and whole inherited model objects are checked against frozen source.
Unknown delta keys/overrides, unavailable or mismatched complete base, overlapping
new names/ranks and dangling refs reject. This physical normative source format
does not change ACE1 value grammar or reinterpret any old catalogue. Final exact
source/identity sizes and hashes are in source-size-audit and runtime evidence.
