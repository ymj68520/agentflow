# Independent registration Oracle and actual coverage

The independent Python implementation reads exact registered source contents,
frozen model@6, the closed successor delta, declared sites/types/rank/body rules
and immutable handwritten logical source fixtures. It never reads Rust Actual
to produce Expected. Its source-site walk is independent of the generator's walk.

Required sites are enumerated from frozen source, not emitted table counts.
Required field/variant coverage includes all appended types, supported output
closure and affected Source/Target/Coordinate/Origin/FactKey/Witness/Evidence and
root/body consumers. Every applicable site, field, variant and rule has stable
CaseIds and Expected. Missing and extra site/field/reference rosters reject.

Manual graph source fixtures are expanded typed **source notation**, not borrowed
views accepted as Nodes. Fixed numeric ranks are explicitly handwritten in
manual-dag-inputs.json. The Oracle derives typed required value/node equality
classes from source, validates proposed node bodies/children/rank constraints,
roots, minimality and reachability and compares complete typed targets. It does
not construct a Raw graph or implement a production rank allocator.

Joint-omission cases supply equally corrupted Expected and Actual views: missing
nodes, roots, map body/entry value/record fields, W references and occurrence
distinctions. Both are checked against independent source/field rosters, not just
against each other. R4's74 old comparator diagnostics remain separate, and new
registration mutations give0 production Full-field Comparator credit.

Native module map cases compile real small AFIDL modules in Rust and independently
in Python. They test input order, full definition changes, missing definitions,
wrong/invalid keys and duplicate keys. Only readonly module mapping is checked;
no Raw Subject graph/rank or Fact is produced. Existing native A/C semantics are
regressed separately without construction-history inference.

The source domain is not broadened to manufacture coverage. A bare float is not
reachable in the Raw guard profile, so it is explicitly ineligible rather than
a fabricated new source site. Exact decimal and U64 mathematical order, Set full
members, empty Map/Set distinction, shared child, explicit Option/variant payloads,
complete document occurrences and W-to-G targets have manual registered subgraphs.

The original G1 file remains48 Not Executed, Actual/ranks null. A new conversion
matrix lists exact related registration subsets and actual receipts where present.
No production-dependent original design vector is promoted: full-condition
executions remain0, even when a related manual/shape subset executes.

The executable census is in the new manifest/registration-audit, not a fixed
minimum case count. Categories separately report Shape, Rule, Structural Site,
DAG Subgraph, Admission Negative, Edition/Portable, Capability Denial and native
module diagnostics. Production Binder Capture CaseIds and production DagRanks
remain0. Cargo Exit0 never replaces the independent external Oracle receipt.
