# C1G1 — Independent Oracle and executable-field-contract DESIGN ONLY

No new formal Oracle, Capture Hook or normalizer is implemented. The40 design
vectors are not run against this algorithm. Existing C1/F1 tests remain separate.
The following is an exact future test contract, not an Expected copied from Rust.

## Inputs and provenance

Inputs are the complete declared source document (physical bytes if genuinely
available), exact parsed declaration if admitted, actual full nine-context
contents/verified object-role partition, exact compiled schemas and complete
compiler/rule sources. No Rust Actual, reason string, record count or caller
claimed checked flag is an Expected input. Required source/Origin unavailable is
an explicit capture-admission error, not an empty passing collection.

The existing replay transport bytes are saved independently from JSON presentation
in replay-wire.json. They cannot be confused with the original unrecorded physical
bytes of a historical native call. Design variables C/D denote actual distinct
objects in later fixtures, not portable object IDs. A future native test must
check real aliasing while borrowing the context; Python consumes the declared
association contract, not an address digest.

## Required field contract

For every applicable event the independent roster contains all of:

```text
full subject/compiler/raw declaration/document/physical association/context
context-role partition and exact source-member association
predicate family/case/parameter/rule-content reference
stage/substage/kind/requirement clause/evidence class/role/dimension
Source/Target/Coordinate/Origin/assertion_path(known empty)
direction/original ordinal/sorted ordinal/U32 port number/predecessor
evaluation/status/full basis/selected-error association
typed contradiction: zero(all fields) | duplicate(all fields) | None-for-P
prerequisites/support/cause relations/reference set/primary/observation edges
applicability and actual-prefix termination boundary
```

Every required explicit option, numeric width and closed tag is compared. No
report reason text is a witness generator. Preserve legacy diagnostics separately
when exposed; canonical display values do not replace raw source fields.
Required instances come from the independently derived applicability roster, not
intersection(Expected.keys, Actual.keys). Both-sided omission must reject.
No authority or token fields are accepted in a mathematical port fact.

Future test statistics must report applicable events, required fields, independently
derived/Actual/compared instances, Missing Expected, Missing Actual, extra fields,
mismatches and unexecuted/unmapped instances separately. None of these is certified
zero by this design. Cardinalities are not inferred from the current40 vectors.
