- R1-F02 (semantic preservation): current set does not promote local P over initialized U. Equal lineage+changed valid body produces final identity U. Addressed by two distinct judgments/bases;not “same key conflicting status.” This conservative availability property is not a P0 and is not repaired here.
- R1-F03 (source adaptation prerequisite): legacy API has no application declaration parameter. Proposed exact declarative envelope is required for future G01 capture;lack of it must fail missing-origin rather than use probe/call order. R3 must add an authorized non-authoritative adapter;ordinary report stays ordinary.
- R1-F04 (execution aggregation): inner execution combined U dominates V,outer cross V dominates U. Explicitly retained in matrix/vector25;flattening the two would change semantics.

- R1-F06 (context subject completeness): the root/Portable RM Context includes resolver_dependencies,but the actual standalone StaticContractProofContext does not. Specify a separate exact nine-field ContractProofContextContents,not an invented empty resolver or a partial old Context. Full projection remains G02;no production getter is added.
- R1-F07 (draft-origin self-review): remove comparisons/results/operands field steps that were not fields of the declared input record. Origins now name the real ApplicationDocument.applications[index] path (old/replacement field only for consumption premises);PredicateId/Dimension identifies the comparison.
