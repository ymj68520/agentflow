# Declarative origin and evidence references

ApplicationOrigin contains the complete ApplicationDocument and actual applications[index] path. checked_operand consumption adds the real old/replacement field only. Other source origins end at that declaration with the closed PredicateId/dimension. No fictional report.results/comparisons path, runtime UUID, timestamp, line number, probe ID, counter or push order is accepted as origin. assertion_path is known empty.

Source appends contract_operand and substitution_application; Target appends contract_operand and substitution_pair; Coordinate appends substitution with typed comparison/member payload, application, optional dimension and clause. EvidenceRef appends contract_operand (typed MemberStep path) and application_declaration. Existing payloads/order remain historical; new cases append only in successor. Full contract/context/comparison coordinates are required instead of invented root/resolver placeholders.

Consumption facts have standalone stage; real validator prerequisite facts retain original stage/path. Typed prerequisites preserve source/target/coordinate/rule/requirement/origin/status/applicability and all consumers. Reference is a full typed evidence coordinate, not RuleId or diagnostic reference text. Derive all references and the typed minimum primary. One originating fact can have many observation/consumer edges. Same inputs in two distinct declared entries have distinct origins; copying a report cannot create a second origin. Contradictory same-origin payloads reject; full FactKey identity enforcement belongs to G01 normalization/G02, not this shape probe.
