# Typed adaptation, source fidelity and stage ownership

## What is implemented

`RawLocalCapture::registered_root_subset` accepts only a seed actually owned by
that sealed capture, validates the genuine event tape, and projects eight exact
registered fields. It checks each against its actual Fact field descriptor, not
a replacement descriptor. A cloned/detached seed is rejected. The returned JSON
is metadata, not a trusted Fact; submitting its shape as Fact fails because the
six remaining roots are absent. Collector insertion still accepts only genuine
captures, never caller-edited subset values.

Evaluation is the tagged `evaluated(unit)` value. Status is `proof(Proven)` or
`proof(Violation)` with the exact capitalized nominal verdict cases. The old
lowercase local trace stays frozen. The local port predicate has no queried
supporting-fact prerequisite or cause. No fabricated earlier component-identity
or schema-parse Proven is added. Companion/substitution/native-guard options are
explicit None; the raw family does not gain another family's basis.

`registered_declared_path` retains the actual five-step path and emits complete
`ModelType{owner,name}`. Every field must occur on that descriptor; each step
passes the existing registered metadata shape check. It does not cast
RawDocumentMember to DeclaredStep or put a document Slot into source_ordinal.

`bound_rejection_witness` returns the actual sealed zero/duplicate witness with
the very same borrowed Subject, compiler, candidate and context. Positive seeds
have no witness. This closes the *borrow association*, not the formal Node rank,
full subject serialization or `TypedContradiction.raw_validation` projection.

## T3 versus T4 and rejected candidate gap

T3 retains the actual predicate/branch, source/target/coordinate/rule/requirement/
origin, semantic evaluation/status, prerequisite/reference/witness/observation
inputs and pending scope association. T4 normalization and G02 full scope are
not implemented. No canonical FactKey/ObligationIdentity/DAG rank is issued.

The initial investigation considered whether every Observation must select
RawValidationFragment.facts by a TypedValue canonical FactKey. That is **not a
confirmed Formal Binding Gap**: the accepted typed-schema materialization §3
explicitly allows descriptive report-carrier paths, not report object references.
The descriptor chain alone does not establish that all legitimate observations
require a map-key selector. The machine audit retains this rejected candidate
and its alternatives; it is not used to stop work with Outcome C.

No particular empty path, guessed report index or guessed alternate carrier is
asserted legitimate. The missing real carrier/site adapter remains incomplete.
No formal Stage/Binding Gap or production/formal contradiction is confirmed.
