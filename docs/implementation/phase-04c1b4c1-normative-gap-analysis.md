G01 is not a proof that current static containment is false. It is a missing formal conformance identity relation for required values. Current six push statements describe implementation behavior, not authoritative normative decisions. In particular "same English" does not imply "same independent source" and "no string" cannot imply "all mandatory proofs Proven".

Subfindings: G01-P/P1 prerequisite identity/discharge; G01-R/P1 reference coordinate versus presentation. A third design dependency, G01-ROLE/P1, records the mixed preflight carrier: five mandatory static entries versus post-gate subflow body evidence. This is not a reported production false-Proven; its resolution is explicit proposed fact roles. The existing gate is intentionally static-only.

The new draft chooses substantive policies instead of borrowing push order: per-origin obligations, separate contradiction retention, explicit blocked dimensions, six independent root boundary facts, scoped subflow facts, exact typed prerequisites/references, full identity Set with ordered encoding. These are **proposed formal additions** justified by preserving the frozen predicates and boundaries; they are not falsely presented as already mandated literal tokens.

All design gaps have a disposition in [decisions](phase-04c1b4c1-decisions.md). Parent G01 remains OPEN/P1 for registration/implementation. G02 OPEN/P1 and G03 OPEN/P2 are separate and not fixed. F01/F02 CLOSED, F03/F04 OPEN/P2, B01/B02 and B03–B07 BLOCKING.
