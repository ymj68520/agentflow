# Reference producer boundary

The R1–R9 reference families identified in the accepted inventory remain unchanged and uncaptured. They include resolver differences, canonical/validation errors and exact ports, EffectAtom/operation/relation operands, caller-local references and full pins, target state, inheritance/downgrade, and Portable getter-only observations. The full [inventory](phase-04c1b4c1-producer-inventory.md) remains source-review evidence, not new registered semantics.

No Debug/Display/hex/colon/slash/reason string is decoded into a Typed Evidence Coordinate. No RuleId is used as a reference. Whole original operands, explicit unresolved requests, full nominal schema/port/atom identity and observation associations must be captured at their real origin when T3 resumes. None of those reference adapters or their independent field comparisons is claimed implemented here.
