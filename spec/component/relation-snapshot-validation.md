# Native Relation Family Source and Current-context Validation

Normative registered staging. A records actual immutable native source; C records
fresh validation under an actual current Context. Neither records unretained
construction history. Native storage/equality and port validation remain unchanged.

A source contains kind, actual schema_family/revision, pin.family/revision/
canonical_content_checksum, complete canonical_content and a closed per-kind
catalog value. The catalog is the explicit lossless RelationCatalogWire.to_value
projection of the complete native T. Its fixed registered wire grammar is not a
claim about the schema used in any historical construction. The nominal kind
table and complete typed descriptors bind this projection; names alone do not.

C lookup is exclusively actual Context.modules. Found retains the full actual
root TypeSchema and full referenced definition closure. Its TypeSchemaRef is a
current validation reference, never the A pin. Canonical schema ACE1 and HashV1
type-schema remain separate from plain catalog SHA256. The full Context retains
all module definitions even where a root digest uses named references.

Actual native CompiledModuleSet rejects duplicate identities and cycles during
construction; Ambiguous applies to malformed metadata candidate collections
before that construction, not a fictitious native lookup branch. A different
family module without the exact requested family yields Missing, not a matching
first candidate. FamilyMismatch applies to conflicting source/slot/definition
metadata. RevisionMismatch requires an actual supplied expected catalog pin;
there is no schema-definition catalog revision or inferred comparison token.

Source refusal precedes lookup and records NotReached. Missing records whether
module, root or referenced definition is absent. Found is intermediate. Invalid
records the actual resolved schema, closed validation step and complete source
input; later checks are not invented. Valid requires catalog canonicalization,
native semantics, current shape encoding, strict decoding, native equality and
byte equality. It is pointwise validity, not universal native-T/schema ABI
equivalence; exact-schema consumers must still check their actual required pin.

None is preserved and executes no catalog validation. Every Some independently
requires Valid for relation admission. This is only the relation portion of
complete Subject admission; all other source/compiler/context/Fact obligations
remain independently required. Successful metadata returns no Fact/Checked token.
The real analysis/canonical_validation pointers must alias; no address is encoded
and no digest/content equality supplies this association. No resolver is added.

Registered failure payloads identify stage and real source/schema/member data,
not parsed Rust diagnostic strings. Port PositiveFresh/Zero/Duplicate decisions
and input-before-output stable sorting remain exactly frozen; none of these
source failures is a Raw port predicate verdict.
